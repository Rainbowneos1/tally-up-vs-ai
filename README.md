# tally-up-vs-ai
A implementation of the board game Tally Up, VS AI. 
# Tally Up 游戏规则

## 目标
率先在**一局结束时**达到 **2500 分或以上**的玩家获胜。若多人达到 2500 分，则分数最高者获胜；若最高分并列，则加赛一轮，分数继续累加，直到分出唯一最高分。

## 游戏组件
- **6 颗彩色积分骰**（红、橙、黄、绿、蓝、紫）
- **1 颗白色加分骰**（Up Die）
- 支持 2~5 名玩家，其中只有你是人类玩家，其余为 AI。

## 骰子信息

| 骰子 | 风险 | 六个面 |
|---|---|---|
| 红 | 高 | ★ ★ ★ 100 50 (50) |
| 橙 | 高 | ★ ★ ★ 70 (70) 50 |
| 黄 | 中 | ★ ★ 70 (40) 20 20 |
| 绿 | 中 | ★ ★ 40 40 (40) 30 |
| 蓝 | 低 | ★ 50 20 10 (10) (10) |
| 紫 | 低 | ★ 20 20 20 (20) (20) |

- **★** = 星星
- **括号数字** = 圆圈数字，例如 (50)
- 数字 = 普通得分

## 一局（Round）的流程

每局由一名**主动玩家**负责掷骰，但所有玩家共同参与决策。

1. **选择骰子**  
   主动玩家从 6 颗彩色骰中**任选 3 颗**，本局内不可更换。

2. **主掷**  
   主动玩家掷出选定的 3 颗骰子，所有玩家查看结果。

3. **结算主掷**  
   - **0 或 1 个星星**：安全。将所有数字累加到本局**累计总分**。若出现至少一个圆圈数字，触发**加分骰**。
   - **2 个星星**：**爆牌！** 本局立即结束，累计总分清零。所有仍 IN 的玩家本局得 0 分；已 OUT 的玩家保留已锁定的分数。
   - **3 个星星**：**Tally Up!** 所有仍 IN 的玩家各获得 **100 分**（直接加入总分）。之后本局继续。

4. **决定去留**  
   若未爆牌，每位仍 IN 的玩家秘密选择：
   - **IN（留下）**：继续冒险，不锁定分数。
   - **OUT（退出）**：立即将当前累计总分加入自己的总分，本局不再参与后续决策。

5. **重复**  
   只要还有人 IN 且未爆牌，主动玩家就再次掷出**同样的 3 颗骰子**（即使他本人已 OUT），重复结算和去留决策。

**本局结束条件**：
- 所有玩家都 OUT，或
- 有人掷出 2 个星星导致爆牌。

本局结束后：
- 累计总分归零。
- 所有玩家状态重置为 IN。
- 主动玩家移交给下一位玩家。
- 新主动玩家重新选择 3 颗骰子，开始新的一局。

## 加分骰（Up Die）

当主掷出现**至少一个圆圈数字**时，触发加分骰。  
在掷加分骰之前，所有仍 IN 的玩家再次决定 IN 或 OUT（OUT 则锁定当前累计总分并退出本局）。  
然后主动玩家掷白色加分骰，结果如下：

| 面 | 效果 | 说明 |
|---|---|---|
| +1 | 奖励掷骰 | 从本局未选中的 3 颗骰子中，选择 1 颗掷出，点数累加 |
| +2 | 奖励掷骰 | 从本局未选中的 3 颗骰子中，选择 2 颗掷出，点数累加 |
| +3 | 奖励掷骰 | 掷出本局未选中的全部 3 颗骰子，点数累加 |
| -100 | 惩罚 | 累计总分减 100（可为负） |
| +100 | 奖励 | 累计总分加 100 |
| ×2 | 奖励 | 累计总分翻倍 |

- 多个圆圈数字只触发**一次**加分骰。
- 奖励掷骰的星星会与主掷的星星**合并计算**。
- 若合并后总星数 **≥ 2**，立即爆牌，累计总分清零，本局结束。
- 奖励掷骰**不会**触发 Tally Up。
- 主动玩家即使已 OUT，仍然负责掷加分骰和奖励骰。在 +1/+2 时，主动玩家可以从剩余骰子中选择；若主动玩家已 OUT，他可能选择星星较多的骰子。

## 得分与爆牌

- **锁定分数**：选择 OUT 时，当前累计总分立即加入总分，之后不再受爆牌影响。
- **爆牌**：累计总分清零，所有仍 IN 的玩家本局得 0 分；已 OUT 的玩家保留已锁定的分数。
- **累计总分可以为负**（例如 -100 后），但爆牌时直接清零，不会将负分带入总分。
- **Tally Up 奖励**：主掷出现 3 个星星时，所有仍 IN 的玩家各 +100 分，直接加入总分。

## 胜利条件

一局结束后，若有人总分 ≥ 2500：
- 若只有一人达到，该玩家获胜。
- 若多人达到，分数最高者获胜。
- 若最高分并列，则加赛一轮，分数继续累加，直到产生唯一最高分。

## 操作提示

- 界面上方显示当前累计总分、回合数和本局骰子。
- 点击「📖 骰子信息」可随时查看 6 颗骰子的所有面。
- 轮到您决策时，使用 IN / OUT 按钮选择去留。
- 所有随机结果出现后，画面会暂停约 0.7 秒，方便您看清结果。
